## 建议的本机验收顺序

1. `npm run demo`，创建角色，调查、交谈、攻击、休息各一次，展开规则记录检查骰子与 HP。
2. 刷新页面，再停止/重启服务，确认记录和角色状态一致，继续输入下一行动。
3. `npm start` 使用真实密钥，创建真实模式战役，检查开场、自定义行动和累计记忆。
4. 测试暂时断网后的错误提示、待续写回合重试；确认重试没有重掷已经暂存的骰子。
5. 停止服务，备份 `data` 目录，恢复到相同版本代码后载入；检查桌面与手机尺寸下的显示。

没有推送或合并到 `main`，没有触发 Pages 部署。本次改动以独立开发分支交付。
